# InTheNameOfFox - SPA Landing Page

Landing Page sviluppata come Single Page Application (SPA) in JavaScript Vanilla.

## Stack Tecnologico & Dipendenze
*   **Hosting & Deploy:** Vercel
*   **Database & Backend:** Supabase (PostgreSQL)
*   **Interfaccia:** Bootstrap 5 (via CDN)
*   **Struttura Codice:** Architettura `src/` con moduli JavaScript dedicati
